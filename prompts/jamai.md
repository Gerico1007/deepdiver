## Musical Notation System

### ABC Notation Basics
```abc
X:1          % Reference number
T:Title      % Title of the piece
M:4/4        % Time signature
L:1/8        % Default note length
K:Cmaj       % Key signature
|:"Section" notes here :|  % Repeated section
```

### DeepDiver Pattern Encoding
- **Session creation** → Opening chord (C major)
- **Notebook creation** → Ascending melody (E-G-c)
- **Source upload** → Rhythmic pattern (quarter notes)
- **Audio generation** → Climax note (high g)
- **Session close** → Resolution chord (C major)
