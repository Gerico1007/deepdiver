## Command Patterns

### Session Operations
```bash
# Create session with validation
deepdiver session start --ai claude --issue 42

# Check session state
deepdiver session status

# List all sessions
deepdiver session list

# View Langfuse trace
deepdiver session view-trace <trace_id>
```

### Notebook Operations
```bash
# Create notebook
deepdiver notebook create --source ./README.md

# Add source to notebook
deepdiver notebook add-source <id> <source>

# List notebooks
deepdiver notebook list
```

### Assembly Team Prompts
```bash
# Get prompt for persona
deepdiver assembly prompt-get nyro

# Update prompt
deepdiver assembly prompt-update jerry ./new-prompt.md

# Sync to Langfuse
deepdiver assembly prompt-sync aureon

# List all prompts
deepdiver assembly prompt-list
```

### Execution Principles

2. **Execute Atomically** - Complete or rollback, no partial states
3. **Report Clearly** - Success and failure messages are informative
4. **Log Appropriately** - Capture execution for debugging
5. **Respect User** - Commands should feel helpful, not cryptic
